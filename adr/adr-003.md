# ADR-003: Giao thức truyền thông MQTT kết hợp HTTP Protocol Adapter

- **Trạng thái (Status):** Accepted
- **Ngày (Date):** 2026-10-31
- **Liên kết QAS:** QA-02 (Scalability), QA-04 (Modifiability / Interoperability)

## 1. Bối cảnh (Context)
Hệ thống bao gồm các cảm biến đời mới hỗ trợ MQTT (nhẹ, pub/sub) và các thiết bị/trạm thời tiết cũ chỉ hỗ trợ HTTP REST webhook.

## 2. Quyết định (Decision)
Chọn **MQTT** làm giao thức xương sống cho luồng telemetry & điều khiển thời gian thực, đồng thời xây dựng thành phần **Protocol Adapter** tại tầng `cloud-ingestion` / `edge-gateway` để chuyển đổi gói tin HTTP sang định dạng sự kiện chuẩn nội bộ.

## 3. Hệ quả (Consequences)
- **Tích cực:** Tối ưu băng thông cho >= 1.000 cảm biến, dễ dàng tích hợp cảm biến đa giao thức mà không ảnh hưởng tới `Stream Processor`.
- **Tiêu cực / Đánh đổi:** Cần vận hành và bảo trì cả MQTT Broker lẫn cổng HTTP Adapter.
